# 自定义地图文件夹

这个文件夹用于存储自定义的地图JSON文件。

## 如何使用

1. 在游戏编辑器中创建自定义地图
2. 点击"保存地图"按钮
3. 浏览器会自动下载一个 `.json` 文件
4. 将该文件移动到本文件夹 (`custom-maps/`) 中

## 地图文件格式

每个地图JSON文件包含以下字段:

```json
{
  "id": "custom_1234567890",
  "name": "我的地图",
  "radius": 4,
  "board": {
    "-3": {
      "0": 0,
      "1": 1,
      "2": 0
    }
  },
  "createdAt": "2026-03-28T12:00:00.000Z",
  "isCustom": true
}
```

## 字段说明

- `id`: 唯一标识符
- `name`: 地图名称
- `radius`: 地图半径 (3-5)
- `board`: 六边形棋盘数据
  - 外层键为 q 坐标
  - 内层键为 r 坐标
  - 值为格子内容: 0=空, 1=玩家1棋子, 2=玩家2棋子
- `createdAt`: 创建时间
- `isCustom`: 标记为自定义地图

## 示例文件

本文件夹可以包含多个地图文件,例如:
- my_custom_map.json
- difficult_level.json
- fun_layout.json

## 注意

- 地图文件必须使用 `.json` 扩展名
- JSON格式必须正确
- 建议使用有意义的文件名
